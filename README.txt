AI in Finance (AIF) — University of Minnesota
=============================================

HOW TO VIEW THE SITE
--------------------
1. Unzip this folder, keeping all files together in one folder.
2. Double-click "index.html" — it opens in your web browser.
3. Navigate using the menu (Home, About, Events, Team, Contact).

Keep every file in the same folder so the design, scripts, and logo load.
Fonts and icons load from the internet, so view it while connected.
